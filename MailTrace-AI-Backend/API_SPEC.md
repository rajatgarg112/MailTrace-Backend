# Backend API Specification

This document details the REST API contract between `MailTrace-AI-Frontend` and `MailTrace-AI-Backend` (served on `main`).

---

## 1. System & Health

### `GET /health`
Returns system status, database connection state, and active subsystem versioning.

#### Response `200 OK`:
```json
{
  "status": "healthy",
  "version": "1.0.0",
  "subsystems": {
    "database": "connected",
    "ml_engine": "ready",
    "security_analyzers": "ready"
  },
  "timestamp": "2026-09-21T09:30:00Z"
}
```

---

## 2. Email Ingestion & Retrieval

### `POST /api/emails`
Ingests an email for pre-delivery security evaluation.

#### Request Body:
```json
{
  "sender": "billing@paypal-support-update.com",
  "recipients": ["victim@example.com"],
  "subject": "URGENT: Verify Your PayPal Account Details Immediately",
  "headers": {
    "Received": "from mail.suspicious.com (185.220.101.5) by mx.example.com ...",
    "Authentication-Results": "spf=fail dmarc=fail"
  },
  "body": "Dear customer, your account will be suspended in 24 hours. Click here: https://bit.ly/3x89qAZ"
}
```

#### Response `201 Created`:
```json
{
  "email_id": "eml_987654321",
  "status": "INGESTED",
  "received_at": "2026-09-21T09:30:00Z",
  "links": {
    "analyze": "/api/emails/eml_987654321/analyze",
    "details": "/api/emails/eml_987654321"
  }
}
```

---

### `GET /api/emails/{email_id}`
Returns normalized email metadata and current decision state.

#### Response `200 OK`:
```json
{
  "email_id": "eml_987654321",
  "sender": "billing@paypal-support-update.com",
  "subject": "URGENT: Verify Your PayPal Account Details Immediately",
  "threat_classification": "MALICIOUS",
  "risk_score": 94,
  "delivery_action": "QUARANTINE",
  "analyzed_at": "2026-09-21T09:30:02Z"
}
```

---

## 3. Analysis Execution & Findings

### `POST /api/emails/{email_id}/analyze`
Triggers or re-runs the Gateway analysis pipeline.

#### Response `200 OK`:
```json
{
  "analysis_id": "anl_123456789",
  "email_id": "eml_987654321",
  "status": "COMPLETED",
  "execution_time_ms": 342,
  "risk_score": 94,
  "threat_classification": "MALICIOUS",
  "delivery_action": "QUARANTINE"
}
```

---

### `GET /api/emails/{email_id}/findings`
Returns detailed findings generated by security and ML modules.

#### Response `200 OK`:
```json
{
  "email_id": "eml_987654321",
  "security_findings": {
    "spf": "FAIL",
    "dkim": "PASS",
    "dmarc": "FAIL",
    "is_lookalike_domain": true,
    "target_domain": "paypal.com",
    "suspicious_url_count": 2
  },
  "ml_findings": {
    "prediction": "PHISHING",
    "confidence": 0.94,
    "urgency_score": 0.89,
    "credential_intent_score": 0.95
  },
  "tags": [
    "DMARC_FAIL",
    "LOOKALIKE_DOMAIN",
    "NEW_DOMAIN",
    "SUSPICIOUS_URL",
    "HIGH_URGENCY",

```

## 4. Forensics & Quarantine

### `GET /api/emails/{email_id}/evidence`
Returns forensic investigation timeline, evidence hashes, and approximate geo-infrastructure context.

#### Response `200 OK`:
```json
{
  "email_id": "eml_987654321",
  "evidence_hash_sha256": "e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855",
  "timeline": [
    {"stage": "INGESTION", "status": "COMPLETED", "timestamp": "2026-09-21T09:30:00Z"},
    {"stage": "AUTH_CHECK", "status": "FAILED", "timestamp": "2026-09-21T09:30:01Z"},
    {"stage": "POLICY_ENFORCEMENT", "status": "ENFORCED", "timestamp": "2026-09-21T09:30:02Z"}
  ],
  "infrastructure": {
    "originating_ip": "185.220.101.5",
    "asn": "AS43350",
    "isp": "NForce Entertainment B.V.",
    "approximate_region": "Frankfurt, Germany",
    "disclaimer": "Approximate network infrastructure location, not verified physical identity."
  }
}
```

---

### `GET /api/quarantine`
Returns paginated list of quarantined emails for the Security Dashboard.

#### Response `200 OK`:
```json
{
  "total": 1,
  "items": [
    {
      "email_id": "eml_987654321",
      "sender": "billing@paypal-support-update.com",
      "subject": "URGENT: Verify Your PayPal Account Details Immediately",
      "risk_score": 94,
      "quarantined_at": "2026-09-21T09:30:02Z"
    }
  ]
}
```
